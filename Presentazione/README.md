# Presentazione CivicLink

Presentazione autonoma in HTML, CSS e JavaScript vanilla per il progetto CivicLink — Smart Community.

## Come aprirla
1. Estrai la cartella `presentazione` dal pacchetto, se hai scaricato lo ZIP.
2. Apri la cartella `presentazione`.
3. Fai doppio clic su `index.html`: si aprirà nel browser. Non serve installare nulla e non serve una connessione Internet.

## Navigazione
- Freccia destra / barra spaziatrice: slide successiva
- Freccia sinistra: slide precedente
- Home: prima slide
- End: ultima slide
- Pulsanti a schermo: Indietro / Avanti
- Pallini centrali: vai direttamente a una slide

## File
- `index.html` — contenuto delle 12 slide
- `style.css` — stile, layout responsive e mockup dashboard
- `script.js` — navigazione e barra di avanzamento
- `assets/civiclink-brand.png` — immagine del brand fornita

La presentazione non utilizza framework, librerie, CDN, server o API.
